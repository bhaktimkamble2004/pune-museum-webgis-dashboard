PUNE HERITAGE MUSEUM WEBGIS — TASK 5
Prepared by: Bhakti Kamble, Geoinformatics Student

HOW TO RUN
1. Start PostgreSQL/PostGIS and GeoServer.
2. Confirm GeoServer is running at http://localhost:8080/geoserver
3. Keep the pune_gis workspace layers published:
   - pune_gis:museum_data
   - pune_gis:museum_lines
   - pune_gis:museum_buildings
4. Open this folder in VS Code.
5. Run index.html using Live Server (recommended). Do not double-click the HTML file.
6. Keep internet access on. Leaflet, Chart.js, the satellite basemap and hero photograph are online resources.

MAP
Default: Esri World Imagery satellite + place labels.
Alternative: OpenStreetMap through the layer control.
GeoServer WMS overlays: point, line and polygon layers.
